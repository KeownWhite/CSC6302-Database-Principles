# CSC6302 Database Principles

Official course workspace for CSC6302.

## Primary Stack

- MySQL Community Server 8.0
- MySQL Workbench
- MySQL Shell
- Java 21
- JDBC / MySQL Connector/J
- Visual Studio Code
- Git

## Workspace Structure

### Exercises

Graded exercises and practice assignments.

Each exercise may contain:

- professor prompt
- working notes
- sources
- MySQL implementation
- diagrams
- screenshots
- optional front end
- optional extension
- exact submitted files

### Quizzes

Quiz questions, answers, review notes, screenshots, and submitted material.

### Projects

Larger database/application projects containing:

- MySQL schema
- queries
- views
- procedures
- testing
- Java/JDBC
- optional front end
- diagrams
- documentation
- optional extensions
- submitted files

### Docs

Course source material and study resources:

- professor slides
- detailed slide summaries
- lecture notes
- study guides
- references
- professor-provided documents

### Database

Reusable MySQL development area for:

- schemas
- queries
- seed data
- tests
- EER diagrams
- backups

### Java

Shared Java/JDBC development area.

### Templates

Master templates used by the course automation scripts.

### Scripts

PowerShell generators for:

- exercises
- quizzes
- projects
- modules

### Scratch

Temporary experiments that are not part of graded work.

## Submission Rule

The `submitted` folder inside each graded item contains the exact files uploaded to Canvas.

It is treated as a frozen historical record after submission.

## Database Design Rule

Every relation should be justified through appropriate database concepts when relevant:

- business rules
- data types
- primary keys
- candidate keys
- superkeys
- foreign keys
- functional dependencies
- normalization
- constraints
- testing

Advanced analysis may be included when it strengthens the required coursework without replacing the professor's requested deliverables.
